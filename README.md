# 🐍 Snake Game

Jogo da cobrinha desenvolvido em Java utilizando JavaFX.

## 🎮 Como jogar

Controle a cobrinha usando as setas do teclado ou WASD.

- ⬆️ W / ↑ - Cima
- ⬇️ S / ↓ - Baixo
- ⬅️ A / ← - Esquerda
- ➡️ D / → - Direita
- ⏸️ P - Pausar

## 🍎 Maçãs

Cada maçã normal aumenta a pontuação em 1 ponto.

A cada 10 pontos aparece uma Super Maçã dourada, que aumenta a cobrinha em 5 quadrados.

## 🛠️ Tecnologias

- Java
- JavaFX
- Maven
- IntelliJ IDEA
